# Цены на продукцию

Код программы, которая собирает в одном окне:

- цены на продукцию: себестоимость из материалов, упаковки и ЗПТ, расчётная и окончательная цена;
- калькуляции артикулов: из каких работ складывается изделие;
- сдельные расценки цеха 1 и цеха 2.

При повышении окладов в расценках калькуляции пересчитываются сами, а раздел цен предупреждает,
что цены, возможно, пора пересмотреть.

## Данных здесь нет

В репозитории только код. Оклады, цены, материалы и калькуляции лежат в локальном файле программы
и в браузере пользователя и сюда не попадают.

## Как работает обновление

Программа открывается файлом с диска. Раз в несколько часов она скачивает отсюда `version.json`
(через GitHub Pages). Если номер версии больше, она скачивает `app.js`, сверяет контрольную сумму
SHA-256 и при следующем запуске работает уже на новом коде. Если новая версия не запустилась,
программа сама возвращается к коду, встроенному в файл.

## Сборка

```bash
python build.py <номер версии> "<что нового>"
```

Исходники — в `src/`: оболочка (`shell.js`), общая тема (`theme.css`) и шаблоны трёх разделов
(`tpl_*.html`). Сборка кладёт `app.js` и `version.json` в корень репозитория, а файл программы с
данными — в соседнюю папку `../ceny-produkcii-dannye/`, которая в git не входит.
